# マイカー点検（自家用車管理アプリ）

iPhone で開くことを想定した、自家用車の点検管理 Web アプリです。
Google スプレッドシートの「自動車点検管理表」を定期的に読み込み、3D の車の各部位に結び付けて表示します。

- トップページに 3D の車（Honda インサイト ZE4 風のファストバックセダン・ブラック、ナンバー「岐阜 303 の 55-10」）を表示。ドラッグで回転、ピンチで拡大縮小
- タイヤ・フロントガラス・ボディ・エンジンルームなどをタップすると、その部位の点検記録を表示
- 「要交換」や期限切れの部位は赤、「要注意」や期限 30 日以内は黄色の丸印で 3D 上に表示
- 設定した間隔（既定 5 分）でスプレッドシートを自動で読み直し。アプリを開き直したときも更新
- 最後に取得したデータを端末に保存するので、電波がないときも前回の内容を表示
- ホーム画面に追加するとアプリのように全画面で起動（PWA）

ビルド不要の静的サイトです（three.js は `vendor/` に同梱）。

## 1. スプレッドシートの準備

1 行目（または上の方の行）に見出しを置き、1 行に 1 項目を書きます。列名は次のどれかを含んでいれば自動で認識します。

| 役割 | 認識する列名の例 | 用途 |
|---|---|---|
| 部位 | 部位 / 箇所 / 場所 / パーツ / 分類 | 3D のどこに表示するかを決める |
| 項目 | 項目 / 点検項目 / 内容 | タイトル |
| 状態 | 状態 / 結果 / 判定 / ステータス | 良好・要注意・要交換 などで色分け |
| 次回 | 次回点検日 / 期限 / 予定 / 交換時期 | 期限切れは赤、30 日以内は黄色 |
| 前回 | 前回点検日 / 実施日 / 交換日 | 表示のみ |
| 備考 | 備考 / メモ / コメント | 表示のみ |

その他の列もすべてそのまま詳細に表示されます。サンプル: [`sample/点検管理表サンプル.csv`](sample/点検管理表サンプル.csv)

### 部位の書き方（3D との対応）

| 3D の部位 | 部位列に書く言葉の例 |
|---|---|
| タイヤ（4 本） | タイヤ、ホイール、空気圧、ブレーキ、パッド。`タイヤ（右前）` `左後` `FR` のように位置を書くとその 1 本だけに表示。位置がなければ 4 本すべて |
| フロントガラス | フロントガラス、飛び石 |
| リアガラス | リアガラス |
| サイドガラス | サイドガラス、窓、パワーウィンドウ |
| ワイパー | ワイパー、ウォッシャー |
| ボディ | ボディ、塗装、洗車、コーティング、キズ、バンパー、ドア |
| エンジンルーム（ボンネット） | エンジン、オイル、バッテリー、冷却水、LLC、ベルト、プラグ |
| ヘッドライト | ライト、ヘッドライト、ウインカー、フォグ |
| テールランプ | テールランプ、ブレーキランプ、バックランプ |
| ミラー | ミラー |
| 車内（屋根部分をタップ） | 車内、エアコン、シート、ドラレコ、ETC |
| 車両全般（画面下のボタン） | 上のどれにも当てはまらない行（車検、保険、税金など） |

言葉の対応表は [`js/sheet.js`](js/sheet.js) の `PARTS` で変更できます。

### 状態の判定

- 赤（要対応）: 要交換、不良、NG、×、異常、要修理 / 次回日付が過ぎている
- 黄（要注意）: 要注意、△、要点検、摩耗、劣化 / 次回日付まで 30 日以内
- 緑（良好）: 良好、OK、○、正常、問題なし、交換済

## 2. アプリとスプレッドシートをつなぐ

アプリ右上の ⚙（設定）にスプレッドシートの URL を入力します。次のいずれかの方法で読み取れるようにしてください。

**A. リンク共有（いちばん簡単）**
スプレッドシートの「共有」→「一般的なアクセス」を「リンクを知っている全員（閲覧者）」にし、ブラウザのアドレスバーの URL をそのまま貼り付けます。タブが複数ある場合は「シート名」にタブ名を入れます（入れない場合は URL の `gid` のタブ、なければ先頭のタブ）。

**B. ウェブに公開（CSV）**
「ファイル」→「共有」→「ウェブに公開」→ 対象シート・CSV を選んで出てきた URL を貼り付けます。

**C. 非公開のまま使う（Apps Script）**
A・B は URL を知っている人なら誰でも読めます。シートを公開したくない場合は、スプレッドシートの「拡張機能」→「Apps Script」で次を貼り付け、「デプロイ」→「ウェブアプリ」（実行ユーザー: 自分 / アクセス: 全員）でデプロイし、発行された `…/exec` の URL を設定に貼ります。URL 自体が合言葉になります。

```javascript
function doGet() {
  const sheet = SpreadsheetApp.getActive().getSheetByName('点検管理表'); // タブ名
  const values = sheet.getDataRange().getDisplayValues();
  return ContentService.createTextOutput(JSON.stringify(values))
    .setMimeType(ContentService.MimeType.JSON);
}
```

車の名前・ボディカラー・ナンバー（地名と分類番号／ひらがな／番号）も同じ設定画面で変えられます。

設定は端末ごとに保存されます。`https://<公開URL>/?sheet=<スプレッドシートURLをエンコードしたもの>&name=愛車` のように URL に付けて開くと、その設定で初期化されます（iPhone に URL を送るときに便利）。

## 記録の追加（＋ボタン）とスプレッドシートへの書き込み

記録の一覧（点検整備・洗車清掃・部位ごと）の右上の ＋ から記録を追加できます。追加した記録はすぐアプリに表示され、同時に点検管理表のその年のシートの日付順の位置に1行挿入されます（年のシートがなければ、一番新しい年のシートをひな形に作ります）。

書き込みには [`gas/Code.gs`](gas/Code.gs)（Google Apps Script）を使います。

1. 点検管理表で「拡張機能」→「Apps Script」
2. `gas/Code.gs` の中身を貼り付け（アプリの 設定 →「スクリプトをコピー」でもコピーできます）、`TOKEN` を好きな合言葉に変えて保存
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行するユーザー「自分」、アクセスできるユーザー「全員」
4. 表示されたウェブアプリの URL と合言葉を、アプリの 設定 →「スプレッドシートへの書き込み」に入れて保存

書き込み先が未設定・圏外などで送れなかった記録は「スプレッドシート送信待ち」として端末に残り、次の更新時に自動で再送します。スプレッドシートから読み戻せた時点で送信待ちは消えます。

## 3. 3D モデル

アプリに組み込んだホンダ インサイト（ZE4・EX BLACK STYLE）の 3D モデルを表示します。実車スキャン（.glb / Gaussian splat）の読み込みは画質が粗かったため廃止しました。

- **車体**：側面写真からトレースした輪郭をロフトした形（`js/body.js`、実寸 L4675 / W1820 / H1410 / WB2700 mm）。ノーズとテールは平面視で丸め、ドアにはキャラクターラインとロアのプレスラインを入れています。
- **細部**（`js/model.js`）：フロントグリル（実車写真に合わせた横桟 6 段＋奥の細い黒桟。桟は厚みと奥行きのある実形状で、わずかに奥へ傾斜）、ナンバー下の横長スロット、クロームのウイングバー、中央の H エンブレム（面取り付きの立体クローム枠と H、ピアノブラックの地と台座。リアの H バッジと INSIGHT の浮き文字も同じ作り、`js/emblem.js`）、HYBRID バッジ（クロームのプレートに青い四角マークと青いイタリック文字の立体バッジ。左フロントフェンダーと、トランクの右テールランプ下。INSIGHT 文字は左テールランプ下。リアの 2 つは蓋と一緒に動き、どのバッジも塗装の曲面に沿って密着）、薄型 LED ヘッドライト（DRL の帯・プロジェクター 3 灯・ウインカー）、左右下部インテーク（横桟 4 段＋最上段に 4 連 LED フォグ。バンパー下部コーナーは実車どおり外側・前方へ張り出し、インテークのハウジングもその角まで伸びる。`js/body.js` の `cornerFlare`）、リップスポイラー、ボンネットのプレスライン、ドアの見切り線・ハンドル・サイドシル・窓枠モール・B ピラーのブラックアウト、ウインカー付きドアミラー、給油口、シャークフィンアンテナ、横一文字のテールランプ（LED の粒と C 型ライトガイド）、トランクスポイラー、H バッジ下のクロームガーニッシュ（塗装面に密着した低い丸断面のモール、両端は閉じた形）、リアのナンバー凹みとナンバー灯、ディフューザーのフィン、タイヤ（トレッド・サイドウォール表記）、10 本 Y スポークのホイール越しに見えるブレーキディスクとキャリパー。
- **開閉**：ダブルタップでドア 4 枚・ボンネット・トランクが開きます（車内・エンジンルーム・トランクの中も作り込み済み）。グリルやライトの開口部はシェーダーで塗装に穴を開け、奥に部品を置いています（`js/detail.js`）。
- 部品は材質ごとにまとめて描画しているので、スマホでも軽く回せます。

## 4. 公開して iPhone で開く

GitHub Pages で公開する手順:

1. このブランチを `main` にマージ
2. リポジトリの Settings → Pages → Source を「GitHub Actions」に設定
3. `.github/workflows/pages.yml` が自動で公開（URL は Actions の実行結果に表示）
4. iPhone の Safari で URL を開き、共有ボタン →「ホーム画面に追加」

※ 非公開リポジトリで GitHub Pages を使うには有料プランが必要です。その場合は Netlify / Cloudflare Pages などの静的ホスティングにこのフォルダをそのまま置けば動きます。

## ローカルで試す

```bash
python3 -m http.server 8000
```

http://localhost:8000 を開きます（`file://` 直開きではモジュールが読み込めません）。スプレッドシート未設定のときはデモデータを表示します。
